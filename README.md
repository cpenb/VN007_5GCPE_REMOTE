## ✨ 主要功能

- **设备状态监控**：实时查看 5G/4G 信号强度、联网模式、运行时间与流量统计。
- **频段锁定与网络优化**：支持锁频（Band Lock）、锁小区（PCI Lock），提升网络连接稳定性与测速表现。
- **设备远程重启**：网络异常或卡顿时一键远程重启设备。
- **短信收发与管理**：远程查看流量卡短信验证码，收发短信无需拔卡。
- **WiFi 与参数配置**：快捷修改 WiFi 名称/密码，支持 APN 与高级参数配置。

## 🚀 使用方法

1. 打开微信扫描上方的小程序码进入小程序。
2. 按照小程序提示添加并绑定您的 VN007 / VN007+ 设备。
3. 绑定成功后即可开始远程管理。
